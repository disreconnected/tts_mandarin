# Roadmap

Future work beyond Phase 1 (not implemented in this codebase yet).

## Phase 2: English TTS and phonetics

- English input with IPA or phoneme-style breakdown.
- Optional comparison of similar sounds.

## Phase 3: Audiobook / long text mode

- Paste or load long passages.
- Automatic sentence segmentation and queue playback.

## Phase 4: User recording and comparison

- Capture microphone audio.
- Align or score user pronunciation against the reference TTS clip.

## Phase 5: Web version

- Backend (e.g. FastAPI) for synthesis and asset handling.
- Frontend (e.g. React) for the same core flows in the browser.
